Mi sitio personal y portfolio profesional, desarrollado con Nuxt 3, donde presento mis proyectos, experiencia y formas de contacto.

🚀 Descripción

Esta web actúa como una tarjeta de presentación interactiva. Incluye una selección de mis proyectos más relevantes, información sobre mi trayectoria profesional y enlaces a mis perfiles y redes.

🧩 Tecnologías

⚡ Nuxt 3 — framework Vue de última generación 🎨 Tailwind CSS — estilos modernos y responsivos 🗂️ @nuxt/content — gestión de contenido en Markdown ☀️ Modo claro/oscuro automático

🔗 Integraciones con GitHub y LinkedIn

📦 Instalación y desarrollo

Clonar el repositorio
git clone git@github.com:RRober97/rescagedo.dev.git

cd rescagedo.dev

Instalar dependencias
npm install

Ejecutar en modo desarrollo
npm run dev

Generar versión estática (para desplegar en Plesk, Netlify, etc.)
npx nuxi generate
